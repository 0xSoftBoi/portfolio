# Visual system

The personal site uses a restrained technical-editorial visual language rather than a cyberpunk/HUD theme.

Design principles:
- evidence and primary-source links over decorative effects;
- serif display type for research/editorial voice, sans-serif for navigation and structure, monospace only for evidence labels;
- off-white paper, graphite, and a restrained green accent;
- diagrams, measurements, and project outcomes should provide visual texture instead of glow, glitch, or stock imagery;
- mobile layouts collapse cleanly without hiding core navigation or evidence;
- Work, Writing, and article pages share `assets/site.css` so the site reads as one publication.
